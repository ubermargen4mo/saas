# Hrips
Браузер на GeckoView + Jetpack Compose (Material 3 Expressive).

Сборка: push в GitHub -> Actions -> Artifacts -> `hrips-apk`.
Локально: Android Studio (нужны SDK Platform 37.1, JDK 17, Gradle 9.6+).

## Версии
- Движок: `geckoVersion` в `app/build.gradle.kts` (стабильные 157.0.*; список на maven.mozilla.org).
- GeckoView 157 требует compileSdk 37.1 и Kotlin 2.4.x, поэтому AGP 9.4.1 + Gradle 9.6.0.
- Android 8.0+ (minSdk 26), проверяется на Android 12 и 16.

## Шрифт
`res/font/roboto_flex_*.ttf` - статические начертания Roboto Flex (латиница + кириллица),
получены из вариативного шрифта сайта (opsz 14, wght 400/500/600/700/800).

## Фоновое воспроизведение
`Media.kt` (MediaHub) принимает события медиа от движка, `MediaService.kt` держит foreground-сервис
типа mediaPlayback и показывает уведомление (пуск/пауза, стоп). В приватных вкладках название и обложка
в уведомлении скрыты. Управляется одна вкладка: та, где воспроизведение началось последним.

Управление: пуск/пауза, стоп; следующий/предыдущий трек и перемотка появляются, если их поддерживает страница.
Видео на весь экран при выходе на главный экран уходит в «картинку в картинке».

## Уведомления сайтов
`SiteNotifications.kt`. Это не push: приходят, пока браузер запущен (открыт, играет медиа или идёт загрузка).
Сайт сначала спрашивает разрешение (диалог в браузере), показ делает система.

## Разрешения сайтов
Камера и микрофон: диалог с галочкой «Запомнить для этого сайта» (`SitePermissions.kt`, в приватных вкладках не запоминается).
Геолокацию и уведомления запоминает сам Gecko. Настройки -> «Разрешения сайтов» показывает всё сохранённое,
позволяет переключить, отозвать (сайт спросит заново) или сбросить все (`SitePermissionsUi.kt`).

## Первый запуск
`Onboarding.kt`: камера, микрофон, местоположение и уведомления просятся одним заходом, затем отдельный шаг
про установку .apk (страница системных настроек). Показывается один раз (флаг `firstrun` в Store).

## Пароли
Включено системное автозаполнение Android (`GeckoView.setAutofillEnabled`), поэтому работают Google Password Manager,
Bitwarden, 1Password и т.п. Сервис выбирается в настройках Android (кнопка есть в настройках браузера).
В приватных вкладках автозаполнение выключено. Собственного хранилища паролей в браузере нет.

## Настройки
`SettingsScreen.kt`: отдельная страница на весь экран (как загрузки). Главная: поиск по настройкам, быстрые
переключатели (реклама, трекеры, подсказки) и разделы с подстраницами: Поиск, Начальная страница,
Конфиденциальность, Пароли, Разрешения, Медиа, Загрузки, О программе. Новые пункты: добавь строку в нужную
подстраницу и запись в `index` (чтобы находился поиском).

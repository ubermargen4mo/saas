# Hrips
Браузер на GeckoView + Jetpack Compose (Material 3 Expressive).

Сборка: push в GitHub -> Actions -> Artifacts -> `hrips-apk`.
Локально: Android Studio (нужны SDK Platform 37.1, JDK 17, Gradle 9.6+).

## Версии
- Движок: `geckoVersion` в `app/build.gradle.kts` (стабильные 157.0.*; список на maven.mozilla.org).
- GeckoView 157 требует compileSdk 37.1 и Kotlin 2.4.x, поэтому AGP 9.4.1 + Gradle 9.6.0.
- Android 8.0+ (minSdk 26), проверяется на Android 12 и 16.

## Шрифт
`res/font/roboto_flex_*.ttf` - статические начертания Roboto Flex (латиница + кириллица),
получены из вариативного шрифта сайта (opsz 14, wght 400/500/600/700/800).

## Фоновое воспроизведение
`Media.kt` (MediaHub) принимает события медиа от движка, `MediaService.kt` держит foreground-сервис
типа mediaPlayback и показывает уведомление (пуск/пауза, стоп). В приватных вкладках название и обложка
в уведомлении скрыты. Управляется одна вкладка: та, где воспроизведение началось последним.

Управление: пуск/пауза, стоп; следующий/предыдущий трек и перемотка появляются, если их поддерживает страница.
Видео на весь экран при выходе на главный экран уходит в «картинку в картинке».

## Уведомления сайтов
`SiteNotifications.kt`. Это не push: приходят, пока браузер запущен (открыт, играет медиа или идёт загрузка).
Сайт сначала спрашивает разрешение (диалог в браузере), показ делает система.

## Разрешения сайтов
Камера и микрофон: диалог с галочкой «Запомнить для этого сайта» (`SitePermissions.kt`, в приватных вкладках не запоминается).
Геолокацию и уведомления запоминает сам Gecko. Настройки -> «Разрешения сайтов» показывает всё сохранённое,
позволяет переключить, отозвать (сайт спросит заново) или сбросить все (`SitePermissionsUi.kt`).

## Первый запуск
`Onboarding.kt`: камера, микрофон, местоположение и уведомления просятся одним заходом, затем отдельный шаг
про установку .apk (страница системных настроек). Показывается один раз (флаг `firstrun` в Store).

## Пароли
Включено системное автозаполнение Android (`GeckoView.setAutofillEnabled`), поэтому работают Google Password Manager,
Bitwarden, 1Password и т.п. Сервис выбирается в настройках Android (кнопка есть в настройках браузера).
В приватных вкладках автозаполнение выключено. Собственного хранилища паролей в браузере нет.

## Настройки
`SettingsScreen.kt`: отдельная страница на весь экран (как загрузки). Главная: поиск по настройкам, быстрые
переключатели (реклама, трекеры, подсказки) и разделы с подстраницами: Поиск, Начальная страница,
Конфиденциальность, Пароли, Разрешения, Медиа, Загрузки, О программе. Новые пункты: добавь строку в нужную
подстраницу и запись в `index` (чтобы находился поиском).

## Браузер по умолчанию, файлы, «Поделиться» и «Искать»
`AndroidManifest.xml`: фильтры http/https (с `APP_BROWSER` для роли браузера), локальные HTML/PDF (`content://` и `file://`,
по типу и по расширению; без `BROWSABLE`, чтобы сайт не мог открыть локальный файл через `intent:`), `SEND text/plain`
(«Поделиться в hrips») и `PROCESS_TEXT` («Искать в hrips»). Разбор в `IncomingIntents.kt`: ссылка из текста открывается,
остальной текст ищется текущей поисковой системой; выделенный текст всегда ищется. Документы копируются в `cache/opened`
(в фоне, старше 7 дней чистятся) и открываются как `file://`, PDF показывает встроенный pdf.js движка.
Кнопка «Браузер по умолчанию» - первая в настройках (`DefaultBrowser.kt`, `RoleManager.ROLE_BROWSER`, на Android 9 и ниже - системные настройки).

## Превью видео
Долгое нажатие или правая кнопка мыши на `<video>` открывает меню с беззвучным зацикленным превью (`VideoPreview` в `ContextMenu.kt`,
MediaPlayer + TextureView). Работает для прямых http(s)-файлов и HLS. Для `blob:` (YouTube и подобные) файла нет, превью не показывается.

## Оживление миниатюр
Встроенное расширение `assets/hover` (`HoverPreview.kt`, переключатель в Настройки -> Медиа). Удержание пальцем или пером 200 мс
на миниатюре шлёт странице события наведения (`pointerover/enter`, `mouseover/enter/move`), при отпускании - `leave/out`.
Если сайт отреагировал (в карточке пошло видео или поменялось содержимое), системное меню подавляется, а клик при отпускании съедается.
Работает только там, где предпросмотр по наведению есть у самого сайта; события синтетические, CSS `:hover` они не включают.
Мышь не трогаем: она наводится сама. Встроенное расширение видно в общем списке расширений.

## Переключатель вкладок
`TabSwitcher.kt`: переключатель «Вкладки / Приватные» из двух связанных кнопок (форма и цвет меняются пружиной), карусель крупных
карточек с превью страницы (центральная крупнее, соседние меньше и бледнее) или сетка, плавающая панель `HorizontalFloatingToolbar`
и большая кнопка «+» в форме печенья. Смахивание карточки вверх закрывает вкладку.
Превью: снимок PixelCopy делается при открытии переключателя и сам, через 1,2 с после загрузки страницы; сохраняется на диск
(`TabThumbs.kt`, кэш `tabthumbs`, до 80 файлов, ключ - адрес), поэтому после перезапуска карточки с картинкой. Приватные вкладки
на диск не пишутся, их превью нет, пока включена защита от скриншотов. Чистится вместе с историей и кэшем.

## Группы вкладок и недавно закрытые
`TabGroups.kt`, логика в `Browser.kt` (`groups`, `closedTabs`, `createGroup/setGroup/ungroup/closeGroup/reopen`).
Удержание карточки в переключателе открывает меню: «В группу…», «В новую группу…», «Убрать из группы», «Закрыть вкладку».
Над списком вкладок появляются чипы групп (фильтр); повторное нажатие или удержание чипа - переименовать, сменить цвет,
разгруппировать или закрыть вкладки группы. Пустые группы исчезают сами. Группы и привязка вкладок сохраняются в `tabs.json`
(поля `groups` и `g`), в приватных вкладках групп нет.
Закрытые обычные вкладки (до 15, в памяти) возвращаются вместе с историей страницы и группой: кнопка «Вернуть» в снекбаре
после закрытия карточки и «Недавно закрытые» в меню «ещё» нижней панели. Приватные вкладки никуда не записываются.

## Соединение и приватность
`PrivacyEngine.kt` применяет к движку четыре настройки из `Store`: HTTPS-only (выкл / только приватные / все вкладки),
защищённый DNS (DoH: выкл / автоматически / строго, провайдеры Cloudflare, Quad9, AdGuard, Google или свой сервер),
Global Privacy Control (включён по умолчанию) и удаление известных tracking-параметров из URL (включено по умолчанию). Вызывается при создании
движка и из `Browser.applyPrivacy()` после каждого изменения в Настройки -> Конфиденциальность (`PrivacyUi.kt`).
Новые значения действуют на следующие загрузки. Свой DoH-адрес сохраняется только после проверки: сервер должен ответить
на тестовый запрос типом `application/dns-message`. Все вызовы GeckoView собраны в `PrivacyEngine`, по одному на настройку.

## Превью вкладок и иконки
`TabThumbs` хранит две копии снимка страницы (обычную и маленькую для сетки). Если снимка нет, `PageImages` берёт картинку из `<meta>`
страницы (og:image и аналоги); для приватных вкладок это не делается, а в Конфиденциальности есть переключатель. Запасной значок сайта
рисует `SiteTile`: цветная плитка с буквой, цвет считается по домену. Подробности и список проверок: `CHANGES.md`.

## Сборка и тесты
Release-сборка идёт через R8 (`app/proguard-rules.pro`), baseline profile лежит в `app/src/main/baseline-prof.txt`. Unit-тесты: `gradle testDebugUnitTest`.
